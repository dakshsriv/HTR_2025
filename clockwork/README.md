# Clockwork: Stop Planning, Start Doing

A task management app designed specifically for high school students with ADHD-Inattentive type.

## Inspiration

Existing task management apps leave ADHD users feeling overwhelmed and bored. Clockwork was built to fix that—a tool that understands how ADHD brains work and removes friction from task completion.

## What It Does

**Clockwork** helps you:
- **Break down tasks intelligently** - Tasks over 45 minutes automatically prompt for subtasks, preventing overwhelm
- **Visualize time pressure** - Color-coded progress bars show how much time remains before your due date
- **Stay focused** - Dual timers for task total and current subtask keep you accountable without judgment
- **Get instant dopamine hits** - Celebration animations on task completion reinforce positive behavior
- **Track what actually works** - Simple analytics show your real patterns (on-time %, streaks, estimation accuracy)

## How It Works

1. **Quick Capture** - Add a task in seconds: title, estimated time, due date
2. **Task Organization** - Tasks auto-sort by closest due date; one task per focus session
3. **Timed Work** - Start a timer and watch the countdown; skip subtasks if you're moving faster
4. **Celebrate Wins** - Finish a task, see the confetti animation, and feel the dopamine
5. **Learn from Data** - Analytics show your productivity patterns without shame

## Built With

- **Flutter** - Cross-platform mobile framework
- **Provider** - State management
- **Local Storage** - All your data stays on your device

## Key Features

✨ **Celebration Animation** - Fun, attention-grabbing confetti bursts on task completion
⏱️ **Dual Timers** - See both total task time and current subtask time side-by-side
📊 **ADHD-Friendly Analytics** - 7 metrics focused on what matters (streaks, on-time %, estimation accuracy)
🎯 **No Breaks Forced** - Skip subtasks instantly without forced break times
⚡ **Minimal Friction** - Get from idea to working in seconds
